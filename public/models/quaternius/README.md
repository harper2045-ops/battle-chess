# Quaternius RPG Character Pack

The six character models in this directory come from the **RPG Character Pack**
by Quaternius (November 2020).

- Source: https://quaternius.com/packs/rpgcharacters.html
- License: CC0 1.0 Universal (public domain)
- Original model names: Cleric, Monk, Ranger, Rogue, Warrior, Wizard

The files are the creator-provided self-contained glTF exports. They include the
idle, attack, receive-hit, and death animation clips used by the battle board.
