# KayKit Adventurers

Selected character models from [KayKit Character Pack: Adventurers](https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0).

The source pack is CC0 and provides optimized, rigged low-poly characters in glTF format. Battle Chess currently uses static idle poses and moves the complete character through its existing presentation pipeline.

- Pawn: Rogue Hooded
- Knight and King: Knight
- Bishop and Queen: Mage
- Rook: Barbarian
